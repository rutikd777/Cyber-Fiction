# Cyber Fiction

Cyber Fiction is a visually immersive web experience that showcases a decentralized community concept in the metaverse. The project features smooth scrolling, animated text, and a dynamic canvas sequence powered by GSAP and Locomotive Scroll.

## Features

- **Smooth Scrolling:** Powered by Locomotive Scroll for a modern feel.
- **Animated Canvas Sequence:** Scroll-triggered frame-by-frame animation using hundreds of PNG images.
- **Responsive Design:** Adapts to different screen sizes.
- **Stylish UI:** Custom fonts and CSS for a futuristic look.

## Getting Started

1. **Clone the repository:**
   ```sh
   git clone https://github.com/yourusername/cyberfiction.git
   cd cyberfiction
   ```

2. **Open `index.html` in your browser.**

> No build step required. All dependencies are loaded via CDN.

## Dependencies

- [GSAP](https://greensock.com/gsap/)
- [GSAP ScrollTrigger](https://greensock.com/scrolltrigger/)
- [Locomotive Scroll](https://locomotivemtl.github.io/locomotive-scroll/)
- [Remix Icon](https://remixicon.com/)
- [Google Fonts](https://fonts.google.com/)

## Customization

- **Images:** Place your PNG sequence in the `img/` folder. Update `script.js` if you change the naming convention.
- **Text & Styles:** Edit `index.html` and `style.css` for your own branding.
